# Savrivo release-candidate artifacts

Snapshot date: 2026-08-20 (Asia/Kolkata)

## Artifact labels

- `*-DEVELOPER-TESTING-debug.apk` files are installable debug builds for development and device testing only. They are not Google Play release artifacts.
- `*-UNSIGNED-RELEASE.aab` files are optimized release bundles, verified to be unsigned. They must be signed with the protected production upload key or through the approved Google Play App Signing workflow before upload.

All eight files are byte-identical copies of the canonical Gradle outputs under `native_android/<module>/build/outputs/` at the time this snapshot was created. SHA-256 values are recorded in `SHA256SUMS.txt`.
